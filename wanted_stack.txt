# (1,196 merged PRs 2026-10-14..28 + 2,555 in-window open PRs, deduped against
# the 454 PR numbers stack.txt already references). Selection rule (operator,
# 2026-10-28): a PR must match BOTH the hardware/transport path we run AND our
# model's shared code. "SM120 but a different model" and "our model but AMD/NPU"
# are NOT wanted (see section R for the drop log; #45474 is the recorded
# counter-example where the tag lies and the code is shared -- verified, keep).
#
# =============================================================================
# PROTOCOL (binding for every agent on this queue)
# =============================================================================
# 1. CODING agents NEVER commit to qwennext-stack, NEVER touch the main
#    worktree (/home/my/sglang/sglang), NEVER edit stack.txt or this file,
#    NEVER push, NEVER restart prod, NEVER run GPU code.
#    Worktree per family:
#      git -C /home/my/sglang/sglang worktree add /tmp/opencode/wt-<NAME> \
#          -b port-<NAME> qwennext-stack
# 2. ONE PR = ONE COMMIT on the staging branch. A test-only follow-up commit
#    belonging to the SAME PR may ride as its own adjacent commit, but two PRs
#    never share a commit. Provenance:
#    - merged upstream: git fetch origin (read-only ok), find the squash commit
#      (git log origin/main --grep='(#N)') and git cherry-pick -x <sha>.
#    - open PR: cherry-pick its commits with -x against the PR head (gh pr view
#      <N> --json commits,headRefOid); squash-port only when the per-commit
#      series is unlandable, and say "[PR #N -- OPEN, squash-ported]" in the
#      message body plus "(cherry picked from commit <head-sha>)".
#    - hand port (fork divergence): re-implement the PR's semantics minimally
#      on our tree, message names the PR + head sha + every deviation.
#    - if a pick conflicts beyond local union resolution, do NOT force it:
#      mark it BLOCKED with the conflict file list and move to the next PR.
# 3. CPU verification ONLY: prod venv python /home/my/sglang/.venv, run from
#    the worktree root with CUDA_VISIBLE_DEVICES=9 and
#    PYTHONPATH=<worktree>/python, and prove the import with
#    python -c "import sglang; print(sglang.__file__)"  -- it must be the
#    WORKTREE path, not the editable prod install.
# 4. LANDING: only the INTEGRATOR agent cherry-picks port-* commits onto
#    qwennext-stack, in the order this file lists them, resolving unions
#    against landed entries. After each PR lands, the integrator deletes its
#    block from wanted_stack.txt and appends it to stack.txt as the next
#    numbered entry (style: existing ledger; numbering continues from 249;
#    '*' = squash/ported marker where applicable), bumping the STACK:/synced:
#    header lines, in one docs commit.
# 5. NOTHING is ever pushed. Live only after user-driven restart.
#
# State tags: TODO | IN-WT(port-<NAME>) | LANDED(entry-XXX @sha) | BLOCKED(why)
